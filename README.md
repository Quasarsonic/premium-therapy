# Premium Therapy (Next.js)

Rebuild of [premiumtherapy.ch](https://premiumtherapy.ch) with a dark, tech-forward visual language inspired by [Re-Activ](https://www.re-activ.ch).

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Hero, pillars, Chi Siamo, featured services
- `/servizi` — Full service list + disturbi trattati
- `/contatti` — Map, contact details, collaborazioni, RME/SNE

Content lives in `src/lib/site-data.ts` for easy updates.
